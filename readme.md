# Delivery Tracker v2 🚚✨

A modern, user-friendly Delivery & Driver Management Dashboard built with **Flask + SQLite**.  
Features:
- Add / Remove deliveries & drivers  
- Update delivery statuses (Pending, Delivered, Failed)  
- Real-time notification panel with timestamps  
- Responsive new-generation UI/UX

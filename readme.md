# NextGen Delivery Dashboard

A modern, friendly delivery dashboard built with Flask + SQLite. Beautiful UI, soft palette, status icons, and full notifications logging every event (add/remove/update).

## Quick start

1. Clone repo
2. Create venv (optional)
3. `pip install -r requirements.txt`
4. Start: `python app.py`
5. Open: `http://127.0.0.1:5000/`

Notifications log: delivery_added, delivery_deleted, driver_added, driver_deleted, status_changed — each with from→to and timestamp.
